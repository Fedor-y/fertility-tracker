Наличие системного Qt не заменяет PySide6. Безопасное решение — изолированная установка Python wheels в .venv: она содержит согласованные версии Qt, не изменяет системный Qt и не смешивает его модули. Полный разрешённый набор Python-зависимостей закреплён в requirements-dev.lock. PySide6 устанавливает свои транзитивные Essentials/Addons/WebEngine/Pdf и shiboken6; дополнительных продуктовых функций это не добавляет.

Git не инициализировался: существующая .git — пустой каталог только для чтения. Пользовательские данные не удалялись. Проверка Git выполнена, но коммитов на этом этапе нет.

## Минимальная реализация

- Точка запуска модуля и консольная команда healthtracker.
- Окно с пустым монохромным графиком и состоянием отсутствия записей.
- Python передаёт готовое пустое представление; JavaScript рисует и возвращает nonce, версию библиотеки и число наблюдений. Подмена nonce/версии/числа не принимается как успешная проверка.
- Все ресурсы локальные. Перехват запросов и навигации запрещает внешние адреса и файлы за пределами ресурсов графика. Дополнительно установлен CSP.
- Off-the-record профиль, без постоянных cookies и localStorage. Страница освобождается раньше профиля.
- Режим --smoke-test закрывает окно после успешного кругового обмена; тайм-аут/ошибка даёт ненулевой код.
- Конфигурация пробной onedir и автоматические тесты каркаса.

Никаких форм, календарных режимов полноценного графика, формул, SQLite-репозиториев, миграций, настроек пользователя и резервирования на этом этапе не реализовано.

## Проблемы и ограничения проверки

- В ограниченной среде недоступны DNS и графический дисплей. Зависимости получены с разрешённым сетевым доступом, Qt-проверки выполнены с доступом к существующему локальному сеансу. Никаких системных установок не было.
- Первоначальная попытка offscreen в sandbox аварийно завершилась; эта попытка не считается успешным тестом. Рабочий способ проверки здесь — текущий Wayland, включая изоляцию сети bwrap.
- Chromium сообщает, что GBM недоступен и применяется Vulkan fallback. Рендеринг, обмен и тесты проходят; sandbox Chromium не отключался.
- PyInstaller предупреждает об отсутствующем необязательном QML-плагине assetdownloader. Каркас использует Qt Widgets; исходники и onedir успешно запускаются. Остальные предупреждения анализа сохранены в build/healthtracker/warn-healthtracker.txt; это не заявление о проверке всех будущих модулей.
- Отсутствие полноценного Git-репозитория не препятствует ENV-01–04, но до коммитов потребуется отдельно разрешённая инициализация либо рабочий checkout.
- Проверены только текущие Arch Linux и графическая конфигурация. Полноценная проверка масштабов, форм, аналитики и финальной поставки относится к последующим этапам.
